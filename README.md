## The entry

A deterministic Node program (`main.ts`, no external dependencies) that writes
one single-line office joke to `/output/entry.txt`:

> My out-of-office reply says I'm on holiday; my calendar says I'm in a meeting called 'Holiday Sync'.

100 characters, one line, UTF-8. Two concrete office artifacts — an
out-of-office reply and a calendar invite — contradict each other, and the
payoff lands in the last words.

## Run

```sh
node main.ts
cat /output/entry.txt
```
